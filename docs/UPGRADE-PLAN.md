# Beastidal 升級計畫：海洋探索、御獸陪伴、移動堡壘

依照 13 點升級需求，排出分三階段的做法。原則：

- 能沿用現有程式、模型與系統就沿用。
- 素材只用免費可商用的，來源與授權記在 `dist/models/CREDITS.md`。
- 每一階段都交付可以實際試玩的版本，先確認小範圍好看、好玩、穩定，再擴大。

工時是以目前一人加 AI 協作的速度粗估，單位是工作天（約 6 小時）。

## 第一階段：核心穩定與畫質樣板（剩下約 8–11 天）

目標：基地和御獸系統不再有卡關或容量死結，並做出一座島＋一段海底遺跡的畫質與效能樣板，確認網頁技術夠用。

1. 地表島嶼樣板：以「中央遺跡島」為題（3–4 天）
   - 用高度圖做起伏地形，取代現在的橢圓島。
   - 植被分三層：草、灌木、樹。
   - 加入風化石造遺跡（模組化牆面、柱子、台階）和一座碼頭。
   - 素材用免費可商用的 CC0 模型，例如 Kenney、Quaternius、Poly Haven；它們的 GitHub 或 npm 鏡像要先確認在這個開發環境能不能下載。
2. 海底遺跡樣板：沉沒神殿入口（2–3 天）
   - 潛水時切換成海底視野：霧色、光束、海床起伏。
   - 一小段可游的遺跡通道和一扇封印門，沿用目前的深潛、氧氣、記憶核心機制。
3. 效能基準與設定（1–2 天）
   - 量測手機與桌機的幀率，把植被密度、陰影、特效、同時出現的生物數量做成畫質分級。
   - 主要測試平台需要你指定，例如哪一支手機、哪一台電腦。
4. 手機操作實測（1 天）
   - 移動、轉視角、互動能不能同時進行；提示會不會遮住畫面。

## 第二階段：串起探索與御獸分工（約 12–16 天）

1. 地圖改成群島內海（第 1、2 點，4–5 天）
   - 外圍做山脈與海岸的遠景（低多邊形遠景，不需要可登陸）。
   - 主海域放四個區域：迷霧島（港口＋隱藏入口）、中央遺跡島、珊瑚島（特殊生態）、海底遺跡區（沉沒建築、封印、長者神殿）。
   - 保留一條通往外海的航道，留給之後擴張。
   - 加入分區載入與遠景簡化，讓地圖變大也不會變慢。
2. 御獸專長（第 7 點，3–4 天）
   - 四大族群各給一項好懂的專長：
     - 淺海：護航，減少風暴與海怪傷害。
     - 陸棲：搜尋資源，標出附近採集點。
     - 深海：深潛，延長氧氣、打開海底通道。
     - 植生：基地生產，船上自動產出口糧或纖維。
   - 專長強弱由基因決定；繁殖畫面顯示親代、可能繼承的特徵、突變，以及後代適合做什麼。
3. 出海目標（第 9 點，3–4 天）
   - 出發前可以選「這趟要做什麼」：採集、找御獸、探索遺跡、解開通道、挑戰敵人。
   - 選好後顯示目的地、所需準備和追蹤標記。
   - 動態事件：夜間生物、退潮入口、暴風後漂流物、御獸發現的線索。主線資源保留穩定的取得方式。
4. 缺什麼就說怎麼拿（第 12 點，1–2 天）
   - 材料不足或條件未達成時，直接說明去哪裡取得，並提供一鍵標記。

## 第三階段：深化戰鬥與堡壘（約 12–15 天）

1. Boss 與敵人（第 10 點，4–5 天）
   - 守望者攻擊前有清楚前兆（水面隆起、低鳴），並留下閃避時機與破綻。
   - 玩家可以命令御獸防護。
   - 先把 2–3 種敵人的行為做完整，再增加種類。
2. 契印能力（第 10 點，2–3 天）
   - 覺醒後解鎖會改變探索方式的能力：護盾保護船隻、穿越危險水流、進入特殊區域。
3. 升級里程碑（第 11 點，3 天）
   - 把融合前的準備拆成 3–4 段任務，分段給回報。
   - 融合完成後，安排一趟會用到貨艙、休息室和艦砲的首航任務。
4. 堡壘擴建（第 3 點後續，3–4 天）
   - 甲板擴建（更多艙位）、自由配置設施、外觀客製。

## 美術方向（第 12、13 點，各階段同步）

- 風格：奇幻自然風。起伏山地、層次分明的森林、風化石造遺跡、青藍海水、神祕的海底氛圍。
- 先統一模型比例、色彩、材質與光影，再加細節。
- 優先改善：海岸、水面、天空、植被分布、地標辨識度、角色動作。
- 樹木、岩石、遺跡牆面、碼頭都做成模組，同一套素材組合出不同區域。
