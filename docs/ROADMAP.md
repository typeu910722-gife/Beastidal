# 比斯泰德 Beastidal 開發路線圖

這份文件記錄「以後慢慢加」的內容方向，讓每次更新都朝同一個世界觀前進。順序是建議，不是承諾；每一階段都要保持單機可玩、存檔向下相容（`validateSave` / `normalize*` 補欄位）、中英文同步（`npm run i18n:check`）。

## 世界觀主軸

主角在通勤途中被砂石車撞死，轉生到一片**被異域裂縫撕開的海洋**。裂縫讓海裡的生物發生異晶突變——這就是御獸的由來，也是之後所有系統（地下城、修煉、季節異變）的共同源頭。

- 第一章（已完成）：活下來 → 擴建木筏 → 點亮遠洋訊號塔。
- 第二章：訊號塔收到回應，發現海面下有「裂縫」在擴大；研究浮標的前主人留下日誌碎片。
- 第三章：進入第一座異域裂縫，第一次帶御獸戰鬥。
- 長線：裂縫的另一端是什麼？主角為什麼會轉生到這裡？

## 1. 劇情系統

- **章節任務**：沿用 `rules.js` 的 quest 結構，新增 `chapter` 欄位與章節過場（複用 `IntroFilm`）。
- **日誌碎片**：散落在島嶼、沉船、裂縫裡，收集後寫入航海日誌（新分頁「記憶」），也計入成就。
- **NPC**：其他漂流者（可以是同樣轉生來的人），在占領的島上定居、提供交易與支線任務。
- **修好筆電**：收集零件修復書桌上的筆電，解鎖主角前世的檔案與裂縫訊號的解析，當作第二章的入口。
- **選擇**：少量會影響結局的選擇（例如：封印裂縫或利用裂縫）。

## 2. 釣魚

- 在船邊或島岸按 E 拋竿 → 等咬鉤 → 小遊戲（拉力條，手機用按住／放開，手把用 RT 力度）。
- 魚種依**海域、時段、天氣、季節**變化；稀有魚是異晶突變魚，可做御獸飼料或研究素材。
- 魚類自動登錄到圖鑑新分類「魚類」；有釣魚類成就（第一條魚、全魚種、暴風雨中釣到傳說魚）。
- 復用：`physics.js` 的浮體計算可直接做浮標與魚線擺動。

## 3. 天氣

目前已有暴風雨警報與晴／陰。擴充成狀態機：

| 天氣 | 影響 |
| --- | --- |
| 晴 | 標準 |
| 霧 | 視距縮短、小地圖範圍變小，稀有漂流物增加 |
| 雨 | 集水器效率 ×2，篝火易熄 |
| 暴風 | 浪高 ×2（Gerstner `WAVE_SET` 振幅）、木筏受損、海中危險生物增加 |
| 異晶潮（稀有） | 裂縫活躍，海面發光，突變率上升，限定御獸出現 |

天氣影響海浪參數、霧、光照、音效與生物生成，全部集中在一個 `weather.js` 模組，存檔只記狀態與剩餘時間。

## 4. 季節

- 一季 = 7 個遊戲日，四季循環；存檔記 `season` 與 `seasonDay`。
- 季節決定：天氣機率、魚種、可採集植物、御獸繁殖期（春季孵化加速）、植生突變御獸開花（春夏）／結果（秋）。
- 冬季：海面部分結冰，可以步行到平時到不了的小島；保暖成為新的生存數值。
- 季節節慶：小型限時活動（漂流燈節、異晶流星雨）。

## 5. 戰鬥系統

目前有艦砲、御獸攻擊（F）與守望者 Boss。下一步做成真正的戰鬥系統：

- **御獸隊伍**：最多 3 隻上場，各自有基因決定的能力（`ABILITIES`）、屬性（海／深淵／陸棲／植生）與羈絆加成。
- **屬性相剋**：海 → 陸棲 → 植生 → 深淵 → 海（循環），混種御獸同時帶兩種屬性。
- **即時戰鬥**：玩家移動走位，御獸自動攻擊，玩家下達技能指令（手機用技能鈕、手把用 LB/RB + 按鍵）。
- **契印技**：已覺醒的御獸解鎖大招，羈絆越高冷卻越短。
- **受傷與照顧**：御獸會倒下但不會死亡，回家休息或用藥草恢復。

## 6. 異域裂縫地下城（修煉）

帶御獸進入地下城、尋找異域裂縫修煉，是戰鬥系統的核心玩法：

- **入口**：海面上的裂縫漩渦、島上的洞窟（晶窟已有雛形）、深海（需要潛水御獸）。
- **結構**：程序生成的房間串（同一個種子 = 同一座地下城，可分享），每層 3–5 個房間 + 裂縫核心。
- **異域裂縫**：地下城深處的裂縫是修煉點——帶御獸站在裂縫中完成挑戰（守住波次、限時擊倒、不受傷通關），成功後：
  - 御獸獲得「裂縫經驗」，提升等級上限或解鎖新基因表現；
  - 有機率觸發**裂縫突變**（新的花紋、元素、或轉成植生突變型）。
- **地下城生態**：裂縫另一端的異界生物，外型和海洋御獸不同（晶體、骨骼、光），可以馴化成稀有御獸。
- **難度與獎勵**：裂縫等級 I–V，等級越高，掉落的異晶與基因素材越好。
- **風險**：隊伍全倒就被沖回海面，掉落一部分背包物資（不會失去御獸）。

## 7. 御獸擴充

- 陸棲御獸的騎乘（在島上奔跑）與攀爬能力。
- 飛行御獸（陸棲・風翼鷗獸的進化）可以短距離滑翔跨島。
- 更多植生突變：苔甲、珊瑚樹、會移動的島。
- 御獸進化：等級 + 條件（季節、天氣、裂縫修煉）觸發外型變化。

## 8. 畫面與效能

- **自適應畫質（第 7 項，延後）**：等畫面細節升級完成後再做，依 FPS 自動在 low / medium / high 之間切換。
- 御獸：更細的皮膚貼圖（法線貼圖）、次表面散射、游動的布料／鰭片模擬。
- 海：泡沫貼圖、焦散、水下霧、天氣相關的浪型。
- 角色動畫：游泳、攀爬、釣魚、戰鬥動作。
