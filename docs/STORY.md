# 比斯泰德 Beastidal 故事聖經

這份文件是劇情的唯一依據。每一階段的劇情、台詞、線索都要和這裡一致；要改設定，先改這份文件。

## 核心問題

> 慈愛組織說要讓世上受苦的人得到解脫。他們的計畫，真的只是那麼單純嗎？

整個遊戲最後要讓玩家自己回答這個問題。組織不是一眼就看得出來的反派：他們確實付了錢、確實讓主角活在一個沒有病痛的世界。問題在於他們說了什麼謊、對誰說謊，以及「解脫」到底是誰的解脫。

## 真相（玩家要到後期才會全部知道）

### 慈愛組織

- 對外是慈善團體，口號是讓世上受苦難的人都得到解脫。
- 專門找**生活困難、家人已經瀕危**的家庭（重傷、末期、昏迷），說服家屬讓瀕危的家人「參與 NW 計畫」。
- 對家屬的說法：病人會進入一個**電腦模擬的世界**，在裡面過沒有病痛的生活；醫療費用由組織**無條件全額負擔**，並持續「治療」，希望病人有一天能醒來。
- 每週給家屬一份**狀態報告**：照片、笑容、「神經反應改善」之類的醫療用語。這些報告是假的，是生成出來的。

### NWProject（異界計畫）與比斯泰德

- 比斯泰德**不是模擬世界**，是一片真實存在的大陸。
- 組織把瀕危者的**意識上傳**，放進在比斯泰德大陸用**基因工程培育的克隆體**裡。玩家操控的主角就是這具克隆體（組織內部叫它「載體」）。
- 現實中，主角的原本身體（「原體」）被維持基本生命徵象，**沒有真的在治療**，只是撐著讓家屬看見組織在付錢、在努力。
- 瀕危者本人完全不知道這些。他們以為自己出了意外、死了、**轉生**到異世界。

### 湖區：適應區

- 第一章的湖與群山是**適應區**：讓新的載體熟悉身體、學會在這片土地上活下去。
- 群山本來是古代「築山的人」為了擋住紫色裂縫而建的（潮之鑰、岩之鑰的記憶）；組織後來利用這座天然的圍牆，把湖當成籠子的門。
- 研究浮標的主人「研究員 K.」是組織的**前導觀測員**，來測試適應區的邊界，想找一條越過群山的路。他想用契約綁住嘯岳失敗，被湖吞沒。
- 嘯岳說的「裂縫在挑選聽得懂野獸的人」，是牠用自己的方式理解組織的篩選。

### 新生之界

- 翻過群山後是一片廣袤的大陸，組織稱它為**新生之界**。
- 在新生之界，玩家可以和**其他玩家**（其他瀕危者）通訊、交流，但**看不見彼此**。
- **新生之界是一座穹頂。** 從裡面看，它是一片真正的野外：草原、森林、河流、遠山、天空、日夜與天氣。實際上它是慈愛組織在比斯泰德大陸上建造的**巨型實驗室**，天空是投影在穹頂內壁上的畫面。
  - 穹頂外才是真正的比斯泰德大陸，以及那道紫色的裂縫。
  - 第一章結尾，玩家越過山脊時看到「裂縫像布幕一樣合上」，其實是走進了穹頂：投影的天空裡沒有裂縫。
  - 穹頂的破綻（逐步揭露）：遠山怎麼走都不會變近；鳥群繞著同一條路線飛；黃昏時天空隱約看得到六角形的接縫；走到邊緣會碰到看不見的牆；穹頂內的雨只下在穹頂裡。
  - 慈光港位在穹頂內，管理區是實驗室對內的出入口之一。

### 主角

- 剛大學畢業的上班族，騎機車通勤途中被砂石車撞成重傷、陷入昏迷。家境不好。
- 媽媽在走投無路時簽下了組織的同意書。參與者編號 **0412**。
- 車禍當天早上傳給媽媽的訊息「媽，我到公司再打給你」沒有寄出去；筆電修好後，訊息狀態顯示「已讀」。

| # | 聲音 | 內容 | 解鎖 |
| --- | --- | --- | --- |
| 1 | …… | 心電監測器的嗶聲 | 第一次睡覺 |
| 2 | 陌生的女聲 | 護理師報血壓，「他今天眉頭皺了一下」 | 調查研究浮標 |
| 3 | 媽媽 | 「慈愛那邊的人說，他們全部負擔」 | 第一隻御獸 |
| 4 | 溫和的男聲 | 同意書、參與者編號 0412、「電腦模擬的世界」 | 看過筆電 |
| 5 | 溫和的男聲 | 給家屬看的假報告：「他在湖邊笑得很開心」 | 第 5 天或擁有戰艦 |
| 6 | 冰冷的聲音 | 「載體」「原體不需要治療」「家屬端報告照常生成」 | 修好筆電 |
| 7 | 媽媽 | 「報告上寫著神經反應改善」 | 嘯岳清醒 |
| 8 | 冰冷的聲音 | 「別讓他知道山的另一邊是真的」 | 與嘯岳締約 |

**修好筆電**：三個零件。電源模組在第一個漂流寶箱，記憶晶片在棕櫚環礁的漂流者寶箱，訊號天線在沉城遺島的御獸文明石碑。修好後還原：慈愛組織寄給家屬的信、`NWP-0412 · 適應期監測` 系統標頭、「已讀」的訊息、本地網路 `NWP-LAKE`、「星圖比對吻合，非模擬資料」。修好後隨身裝置的訊號欄從「無訊號」變成 `NWP-LAKE`。

**研究員署名**：研究浮標紀錄末尾「研究員 K.——NWP 前導觀……（以下毀損）」。

**第一章結尾**：越過山脊，看見大陸與城市燈火，紫色裂縫像布幕一樣合上，天空廣播「恭喜您完成適應期。歡迎來到新生之界……您的家人一切安好。慈愛組織，與您同在。」嘯岳認出這是研究員盒子裡的聲音。

### 0.47 · 第二章（上）慈光港

**慈光港**是翻過群山後的第一座港城（`dist/town.js`、`dist/town-models.js`）。城裡什麼都有，乾淨、免費、溫柔，但是**空無一人**：窗戶亮著燈、門口擺著鞋、餐館的湯還在冒煙、廣場上有腳印。唯一看得見的人是引路人。

- **引路人・晴**：慈愛組織的職員，穿白色制服，站在新生歡迎中心前。開口第一句說溜了嘴：「歡迎回家，0412 號。」她知道車禍那天早上在下雨，主角從沒告訴過任何人。她發給主角居民證 No.0412、新生者手冊和公寓房間。
- **嘯岳不進城**：「這裡的味道不對。像研究員的盒子，像沒有風的湖。」牠在城門外等，也是回湖區的方法。
- **一切免費**：公寓 0412 號房（可以睡覺）、配給站每天的口糧和淡水（味道像醫院的流質）。
- **在城裡睡覺不會有回聲**：「這裡睡得很沉，一個夢都沒有。」組織在壓制。
- **留言碑**：其他居民的留言，只能讀不能回（第 3 階段開放）。No.0156 的「別相信——」後半段被磨掉了，刻痕很新。
- **家書亭**：從見到晴那天起，每 7 天一封媽媽的信，一共 3 封。每封都溫暖，每封都有破綻：
  1. 提到「你說到公司再打給我」，但那則訊息**根本沒寄出去**（筆電上顯示「已讀」，讀的人是組織）。
  2. 「湖邊笑的照片」，和夢裡假報告的說法一模一樣。
  3. 「如果你醒過來」，可是主角以為自己已經死了。
- **管理區**：「僅限職員」，白天鎖著。讀過第一封信後，夜裡去看會看到門縫的白光，聽到夢裡那個冰冷的聲音。這是**第二章（上）的結尾**。

### 0.48 · 穹頂下的野外與看不見彼此的通訊

**野外**（`dist/dome.js`、`dist/dome-models.js`）：慈光港四周是一片半徑約 290 公尺的野外，有起伏的草原、六片森林、一條河和一座木橋、在林邊吃草的鹿、繞圈飛的鳥群。

**穹頂的破綻**（每個只記一次，記進日誌「新生之界 · …」）：

| 破綻 | 觸發 |
| --- | --- |
| 天上的紫色裂縫不見了 | 第一次在新生之界 |
| 遠山一點也沒有變近 | 離廣場走到 170 公尺外 |
| 看不見的牆，閃過六角形的光 | 走到穹頂邊緣（每次碰到都會閃） |
| 鳥群飛的路線跟剛才一模一樣 | 在野外待滿 150 秒（白天） |
| 鹿每天走同一條路 | 在野外待滿 300 秒 |
| 夕陽下天空有一格一格的線 | 黃昏（約 17:30–19:12）身在新生之界 |

**通訊**（`dist/comms.js`）：居民彼此看不見，只能透過留言碑交流。

- **片語留言**：句型＋詞，每天 3 則，其他居民會共鳴、回應（「……我也是。」）。
- **漂流信**：一次一封，一到兩天後收到某位居民的回信。回信也是線索，例如「再讀一次你的家書。仔細讀。」「這裡的雨，好像只下在城裡。」
- **殘影**：野外偶爾出現發光的腳印，走近就散。
- **審查**：用了「嗶嗶聲、醫院、山的另一邊、穹頂、管理區」的留言，隔天會被移除，只剩「本則留言因違反居民守則，已由慈愛組織移除。」漂流信會被蓋章退回。晴會在下一次交談時溫柔地提起：「有些話，說出來只會讓大家不安喔。」

## 寫作原則

- **組織的聲音永遠溫柔。** 他們不威脅、不命令，只關心、只保證。恐怖感來自玩家發現溫柔底下的東西。
- **主角會替線索找藉口**（「只是夢」「電腦壞了」），玩家會比主角早一步起疑。
- **冷靜、寫實的細節**勝過驚悚：血壓數字、同意書頁數、報告用語。
- 第一章**不直接說出**「克隆」「上傳」這些詞；「載體」「原體」是最多能透露的。
- 家人是真心愛主角的；媽媽沒有做錯，她只是被騙了。
