# 比斯泰德 Beastidal 故事聖經

這份文件是劇情的唯一依據。每一階段的劇情、台詞、線索都要和這裡一致；要改設定，先改這份文件。

## 核心問題

> 慈愛組織說要讓世上受苦的人得到解脫。他們的計畫，真的只是那麼單純嗎？

整個遊戲最後要讓玩家自己回答這個問題。組織不是一眼就看得出來的反派：他們確實付了錢、確實讓主角活在一個沒有病痛的世界。問題在於他們說了什麼謊、對誰說謊，以及「解脫」到底是誰的解脫。

## 真相（玩家要到後期才會全部知道）

### 慈愛組織

- 對外是慈善團體，口號是讓世上受苦難的人都得到解脫。
- 專門找**生活困難、家人已經瀕危**的家庭（重傷、末期、昏迷），說服家屬讓瀕危的家人「參與 NW 計畫」。
- 對家屬的說法：病人會進入一個**電腦模擬的世界**，在裡面過沒有病痛的生活；醫療費用由組織**無條件全額負擔**，並持續「治療」，希望病人有一天能醒來。
- 每週給家屬一份**狀態報告**：照片、笑容、「神經反應改善」之類的醫療用語。這些報告是假的，是生成出來的。

### NWProject（異界計畫）與比斯泰德

- 比斯泰德**不是模擬世界**，是一片真實存在的大陸。
- 組織把瀕危者的**意識上傳**，放進在比斯泰德大陸用**基因工程培育的克隆體**裡。玩家操控的主角就是這具克隆體（組織內部叫它「載體」）。
- 現實中，主角的原本身體（「原體」）被維持基本生命徵象，**沒有真的在治療**，只是撐著讓家屬看見組織在付錢、在努力。
- 瀕危者本人完全不知道這些。他們以為自己出了意外、死了、**轉生**到異世界。

### 湖區：適應區

- 第一章的湖與群山是**適應區**：讓新的載體熟悉身體、學會在這片土地上活下去。
- 群山本來是古代「築山的人」為了擋住紫色裂縫而建的（潮之鑰、岩之鑰的記憶）；組織後來利用這座天然的圍牆，把湖當成籠子的門。
- 研究浮標的主人「研究員 K.」是組織的**前導觀測員**，來測試適應區的邊界，想找一條越過群山的路。他想用契約綁住嘯岳失敗，被湖吞沒。
- 嘯岳說的「裂縫在挑選聽得懂野獸的人」，是牠用自己的方式理解組織的篩選。

### 新生之界

- 翻過群山後是一片廣袤的大陸，組織稱它為**新生之界**。
- 在新生之界，玩家可以和**其他玩家**（其他瀕危者）通訊、交流，但**看不見彼此**。
- **新生之界是一座穹頂。** 從裡面看，它是一片真正的野外：草原、森林、河流、遠山、天空、日夜與天氣。實際上它是慈愛組織在比斯泰德大陸上建造的**巨型實驗室**，天空是投影在穹頂內壁上的畫面。
  - 穹頂外才是真正的比斯泰德大陸，以及那道紫色的裂縫。
  - 第一章結尾，玩家越過山脊時看到「裂縫像布幕一樣合上」，其實是走進了穹頂：投影的天空裡沒有裂縫。
  - 穹頂的破綻（逐步揭露）：遠山怎麼走都不會變近；鳥群繞著同一條路線飛；黃昏時天空隱約看得到六角形的接縫；走到邊緣會碰到看不見的牆；穹頂內的雨只下在穹頂裡。
  - 慈光港位在穹頂內，管理區是實驗室對內的出入口之一。

### 主角

- 剛大學畢業的上班族，騎機車通勤途中被砂石車撞成重傷、陷入昏迷。家境不好。
- 媽媽在走投無路時簽下了組織的同意書。參與者編號 **0412**。
- 車禍當天早上傳給媽媽的訊息「媽，我到公司再打給你」沒有寄出去；筆電修好後，訊息狀態顯示「已讀」。

### 0.47 · 第二章（上）慈光港

**慈光港**是翻過群山後的第一座港城（`dist/town.js`、`dist/town-models.js`）。城裡什麼都有，乾淨、免費、溫柔，但是**空無一人**：窗戶亮著燈、門口擺著鞋、餐館的湯還在冒煙、廣場上有腳印。唯一看得見的人是引路人。

- **引路人・晴**：慈愛組織的職員，穿白色制服，站在新生歡迎中心前。開口第一句說溜了嘴：「歡迎回家，0412 號。」她知道車禍那天早上在下雨，主角從沒告訴過任何人。她發給主角居民證 No.0412、新生者手冊和公寓房間。
- **嘯岳不進城**：「這裡的味道不對。像研究員的盒子，像沒有風的湖。」牠在城門外等，也是回湖區的方法。
- **一切免費**：公寓 0412 號房（可以睡覺）、配給站每天的口糧和淡水（味道像醫院的流質）。
- **在城裡睡覺不會有回聲**：「這裡睡得很沉，一個夢都沒有。」組織在壓制。
- **留言碑**：其他居民的留言，只能讀不能回（第 3 階段開放）。No.0156 的「別相信——」後半段被磨掉了，刻痕很新。
- **家書亭**：從見到晴那天起，每 7 天一封媽媽的信，一共 3 封。每封都溫暖，每封都有破綻：
  1. 提到「你說到公司再打給我」，但那則訊息**根本沒寄出去**（筆電上顯示「已讀」，讀的人是組織）。
  2. 「湖邊笑的照片」，和夢裡假報告的說法一模一樣。
  3. 「如果你醒過來」，可是主角以為自己已經死了。
- **管理區**：「僅限職員」，白天鎖著。讀過第一封信後，夜裡去看會看到門縫的白光，聽到夢裡那個冰冷的聲音。這是**第二章（上）的結尾**。

### 0.50 · 第三章（上）橋

`dist/chapter3.js`。兩條結局在這裡會合：

1. **撕開穹頂**：「穹頂之外」結局一開始就是開的。「遺忘」結局要回城門外找嘯岳：「你忘了什麼，對吧？我記得。」請牠再撕一次。
2. **穹頂外 · 裂縫荒原**：從城門南邊、穹頂盡頭的裂口走出去，是乾裂的灰土。回頭看，穹頂是一座六角形的外殼，裡面的一切都是投影；這一側的天空有紫色的裂縫。
3. **研究員 K. 的前哨站**：三段錄音。
   - 一：K. 是前導觀測員，負責確認載體能不能活下去。御獸聽得懂載體，這不在計畫裡。
   - 二：**裂縫是一座橋**，一端是比斯泰德，一端是我們的世界。組織把意識從橋上送過來，裝進這邊培育的身體。董事會稱之為慈悲。
   - 三：K. 要的「路」是**回去的路**：意識能過來，就能回去，原體還活著的人還來得及。他進了裂縫。「別讓他們『畢業』你。」
4. **裂縫 · 第一層**：帶最多 3 隻御獸，打 3 波（裂縫晶骸、空殼載體、裂縫守門者）。每回合選一個戰術：猛攻、守勢（減傷、回血）、契印技（覺醒或遠古御獸才能用，每波一次，打全體）。敵人強度會配合隊伍調整，只按猛攻多半會輸。御獸不會死，輸了只會受傷。第一次通過得到**核心碎片**。
5. **核心的幻象**：病房、瘦下去的原體、握著那隻手睡著的媽媽：「你今天，好像又動了一下。」嘯岳：碎片只有一塊，裂縫還有更深的層。→ **第三章（上）完 · 橋**。

2. **裂縫 · 第三層**：頭目是**空殼 · 研究員 K.**。他走到了核心，但他的原體在他進來的那一週就被「維持結束」。他告訴你：走過橋的人會失去這一邊的身體，御獸會留在這邊。
3. **橋**：三塊核心碎片在裂縫核心拼成一座橋，另一頭是病房。**管理者**第一次開口，他是新生之界的建造者：回去的是意識，這具身體、御獸和嘯岳都會留下；原體撐不了太久，媽媽前天簽了第二份文件。→ **第三章 完 · 橋的兩端**。

### 0.73 · 第四章（上）第二份文件

`dist/chapter4.js`。橋已經搭好，但在做決定之前，主角先去弄清楚三件事：

1. **K. 的終端機**：三塊碎片接上前哨站的終端機，連到組織的系統。第一份文件是 NW 計畫參與同意書；**第二份是「原體維持終止同意書」**，媽媽兩天前簽的，執行日期是七天後上午九點。附註寫著「參與者意識已於新世界安詳生活，原體持續承受痛苦，延長維持並無意義」：媽媽不是放棄，她是被告知主角已經在別處好好活著。畢業排程：0156（已完成）、0388、0412。K. 的主控權限還有效。

   - 「穹頂之外」線：晴在裡面。她因為放走主角，被「意識封存、載體回收」，但她的原體還被維持著，用來繼續寄家屬報告。
   - 「遺忘」線：槽是空的，標籤「0001 · 備用」，替她不再有用的那一天準備的。
4. **管理者的第二句話**（回到橋）：媽媽累了，也需要解脫；「畢業」省下維持費用，董事會很滿意。他給主角另一條路：**留下來，當下一個晴**，只要替組織工作，原體就會被維持，媽媽就會繼續收到照片。主角問：「解脫，是誰的解脫？」管理者：「你慢慢想。我讓他們等你。」嘯岳說他說話沒有味道，像那個盒子。橋的另一頭，媽媽手邊有一支筆。→ **第四章（上）完 · 第二份文件**。

### 第四章（下）牽絆（設計）

選擇本身不難，難的是捨不得。第四章（下）先讓玩家**親眼看見自己在比斯泰德留下了什麼**，再讓他選。所有回憶都來自玩家自己的存檔，不是寫死的劇情：每個人看到的都不一樣。

1. **夥伴的話**（0.74）：每隻契約御獸都記得和你的關鍵時刻（締約那天、第一次出門、一起打倒的強敵，這些**永遠不會被新的記憶擠掉**）。在御獸倉庫對牠「說說話」，牠會說出只屬於你們的事；羈絆越深，牠越察覺你可能要走了。第一隻從漁網裡救起的夥伴，戲份最重。
2. **走一圈你的家**（0.74）：回到木筏上，走近自己親手蓋的設施，會浮現那一天的回憶（「第 5 天，你在這裡蓋好了避難所。那天晚上，第一次睡得著。」）。
3. **嘯岳的過去**：嘯岳曾經也有一個「聽得懂野獸的人」——那個人走過了橋，沒有再回來。牠守著湖、一直說「我記得」，因為被留下的是牠。若主角選擇過橋，嘯岳會說：「這次換我送你。」
4. **回去的代價**：原體躺了太久，也許再也走不了路；家裡為了醫藥費負債，媽媽一個人在撐。在比斯泰德，你能駕船、和野獸說話、蓋起一整座家；回去，你是病床上的人。
5. **最後一天**：選擇之前，有一整天可以自由度過——和御獸釣魚、去占領過的島、在木筏上看夕陽。每件事都會留下一段回憶，寫進結局。
6. **三條路與結局**：走過橋（尾聲依每隻御獸的羈絆，演出牠們之後的樣子：羈絆最深的那隻每天回木筏等你；嘯岳回到山腳，等下一個人）；留下當引路人（媽媽最後一次來，對著那張「湖邊微笑」的照片說話）；第三條路（用 K. 的主控權限救 0388、放出或說服晴、在裂縫最深處關掉「畢業」、把真相刻上留言碑；最後媽媽用那支筆撕掉了第二份文件）。

## 寫作原則

- **組織的聲音永遠溫柔。** 他們不威脅、不命令，只關心、只保證。恐怖感來自玩家發現溫柔底下的東西。
- **主角會替線索找藉口**（「只是夢」「電腦壞了」），玩家會比主角早一步起疑。
- **冷靜、寫實的細節**勝過驚悚：血壓數字、同意書頁數、報告用語。
- 第一章**不直接說出**「克隆」「上傳」這些詞；「載體」「原體」是最多能透露的。
- 家人是真心愛主角的；媽媽沒有做錯，她只是被騙了。
