# 比斯泰德 / Beastidal

第一章可玩原型：大學畢業後騎機車上班的主角，在砂石車碰撞後轉生到海洋異世界，並逐步發現海底隆起的新生礁島。通勤、碰撞與轉生以可跳過的即時 3D 動畫呈現。

## 玩法

打撈漂流木、金屬、纖維、異晶、口糧與水，擴建兩格地基、避難所、蒸餾器與遠洋訊號塔完成第一章。生命、水分與飽食形成生存循環，危險生物可用船槳驅離，失去意識時返回木筏並損失部分木材和金屬。

東北方研究浮標解鎖隱藏共生任務。建造海洋展示池後投餌，建立信任並馴化生物。每池三個名額，孵育卵也會預先占位。馴化生物會在池中游動展示並依基因能力提供物資或防護。

建造基因孵化台，選兩隻不同的個體，消耗一份異晶與兩份口糧，三十秒後孵化。每台可同時培育兩顆卵。後代可繼續交配。

16 個基因座，每個有兩個 0–255 的等位基因。後代每個基因座各從兩親代隨機繼承一個等位基因，再對各等位基因以 4.5% 機率突變。以 256^32 個有序編碼構成龐大的有限空間，不宣稱数学上的無限，也不宣稱每個編碼都有完全獨特的外觀。身體、鰭、尾巴、觸角、眼睛、紋路、色彩、光度和體型控制 3D 模型；能力基因影響生產與防護。

## 存檔與平台

存檔使用此裝置此瀏覽器的 localStorage，每 8 秒及重要行為後自動保存。不同手機、電腦之間不會同步；清除瀏覽資料會移除進度。暫停及切出分頁時停止遊戲時間。需要支援 WebGL 2 的瀏覽器，建議開啟硬體加速。

0.2 版新增小艇停泊、角色登岸、木筏步行與登艇。木筏邊緣會阻止角色走入海中，展示池不視為可行走地面；集水器和孵化台具有步行碰撞。舊存檔會自動補上移動狀態。手機以橫屏配置左右拇指操作區、中央快捷列與瀏海安全邊界；直向時顯示旋轉提示並暫停，橫放後恢復。全螢幕與方向鎖定使用能力偵測，不支援的瀏覽器仍可手動橫放遊玩。

純靜態 HTML/CSS/ESM，所有遊戲依賴隨檔提供，沒有 CDN、伺服器資料庫或付費 API。`dist/` 為網站內容。程式模組：`world.js` 即時 3D 與動畫、`game.js` 輸入/UI/流程、`rules.js` 生存與經濟、`genetics.js` 基因、`navigation.js` 停泊與步行、`mobile.css` 橫屏介面。

## 開發與驗證

使用任何靜態 HTTP 伺服器提供 dist 目錄。模組無法透過 file:// 直接開啟。

```sh
npm run check
npm test
```

第三方圖形庫 Three.js 0.180.0，MIT 授權，授權文件在 `dist/vendor/THREE-LICENSE.txt`。

此版本是一章原型，尚未包含多人連線、跨裝置雲端存檔、完整配音及長篇劇情。真實手機 GPU 效能與個別手把相容性需要實機測試。

## 0.3 島嶼與模型更新

- 建築模型可直接點擊，或靠近後用 E／手把 A／互動按鈕開啟。實際操作距離為 5.5 公尺。避難所消耗各 1 口糧與淡水恢復 45 體力；集水器每 35 秒儲存 2 水，上限 20，需點擊取出。展示池顯示本池住民，孵化台開啟基因配對，訊號塔掃描後顯示遠方島名與採集點。
- 棕櫚環礁、異晶礁島、沉城遺島可登岸探索。日誌 J 有航線按鈕，靠近海岸使用 Q／LT／登岸按鈕。島上走近 4 公尺內採集，120 秒後恢復；異晶礁島提供較多異晶，沉城遺島提供較多金屬。原有海上建造區維持在木筏周圍，島上暫不開放建造。
- 魚、魟、水母、海龜使用各自的連續身體網格、鰭膜、觸鬚或龜甲紋理；不再套用同一組球體、尾巴與鰭。展示池分成三個游動位置，降低模型重疊。尖首木艇、帆布屋頂、儲水桶、孵化台、展示池與訊號塔增加結構細節，角色手腳改為圓滑肢體。
- 第一人稱支援 Pointer Lock 滑鼠環視：切換到第一人稱或點一下畫面啟用，Esc 釋放。開選單自動釋放；瀏覽器拒絕鎖定時可按住右鍵拖曳。手機滑動與手把右搖桿仍可環視。
- 沿用舊存檔鍵值。既有物資不會扣回，新水產出改儲存在水桶；島嶼下方的漂流物會移到海岸外。

驗證：21 項規則／模型測試，另以模擬 DOM 驗證設施點擊、取水、滑鼠位移、航線選單、孵化、手把與橫屏流程；DOM 測試使用繪圖替身，未代替真實手機、GPU 或滑鼠鎖定權限的實機驗證。

## 0.4 展示池住處管理

每池最多 3 隻，孵育卵預留入住名額。共生研究的展示場頁籤與展示池點擊面板可選目的池搬移；若目標已滿，可指定另一隻生物互換。住處使用池子座標識別並隨存檔保存，孵化後保留預約池。舊存檔自動分配空位，超額生物保留為待安置（不擠入模型展示），增建池後自動安置；基因不變。

## 0.4.1 下載版

點擊展示池只顯示該池住民、該池住處操作與該池預留幼體；全體名單保留在共生研究。空池不會列出其他池住民。桌面面板與對話框加寬至最多 760px，字級與生物預覽同步放大；手機橫屏面板接近滿屏、內容可捲動且保留安全邊界。本次修改以 ZIP 交付，線上版未同步更新。

## 0.4.2 自訂展示池名稱

點擊展示池，在面板上方輸入名稱並儲存；最多 16 個字。名稱同步到展示池標題、互動提示、住處與搬移選單、幼體預留資訊，並隨進度自動儲存。不更改池子識別碼或住民安排。留白、過長與重複名稱會顯示原因。

## 0.5 御獸生存：本包目前版本

此包整合 0.4.2 的池名、每池 3 隻、個別池面板與放大彈窗，以及以下新玩法；依然是單人瀏覽器原型。未更新線上 Site。

### 御獸與羈絆

按 K 或「御獸遠航」開啟管理。一次出戰一隻，出戰不釋放原展示池名額。

| 羈絆 | 解鎖 |
| --- | --- |
| 15 | 跟隨、協助採集 |
| 30 | 攻擊敵對生物、守護協戰 |
| 35 | 可作為雜交親代（兩親代皆需達標） |
| 45 | 海上騎乘 |
| 60 | 騎乘深潛至 8 公尺 |
| 85 | 完成遺跡與海怪挑戰後，花 12 異晶喚醒契印 |

野生投餌每次信任 +5～10，間隔 18 秒，約需 10～20 次；連點不會消耗第二份誘餌。馴化與舊存檔夥伴的初始羈絆為 10，原有基因和池子分配保留。訓練花 2 口糧＋1 異晶，羈絆 +4、耐力與體力各 +15，冷卻 90 秒。出戰同行每分鐘 +0.75；成功協採 +1。通常需持續培養十餘分鐘才會解鎖騎乘，具體取決於訓練與採集頻率。

協採每 45 秒嘗試一次：海上回收附近 12 公尺漂流物；島上回收身旁 4 公尺的可用採集點。守護模式會對附近敵對生物自動攻擊。攻擊消耗耐力，回池可恢復耐力與體力。已派出夥伴的狀態在畫面顯示。

T 騎乘／解除、G 潛水／浮上、F 夥伴攻擊；手機使用畫面按鈕。手把 RT 在有夥伴時改為攻擊，沒有夥伴時維持驅離，Select 開啟御獸面板。小艇停留在出發處；H 可標記返回小艇，回到 7 公尺內才可解除騎乘。此版需先回小艇再登島，尚不支援直接從坐騎登陸。深潛氧氣最多 90 秒，耗盡自動浮上；騎乘耐力耗盡會緊急返回小艇並損失 8 體力。

### 雙親外形與突變

形態基因不再以雙親數值取平均決定單一種類。主體使用來自第一親代的形態等位基因，第二親代的等位基因決定追加翼膜、龜甲、觸鬚傘膜或尾刃；後代仍可把繼承的形態傳下去。多眼、晶觸角、骨棘、發光絲帶等強化突變感，且依基因改變。現有基因資料不重抽。契印覺醒加上環形靈光與攻擊 +12；完整幻獸進化樹、專屬稀有種與多技能配置尚未加入。

### 建築擴充

B 建造：新增二樓地板、樓梯、椅子、工作餐桌、晶光燈。施工樓層可切換。先在既有地基上蓋二樓地板，再在同格空間放樓梯；走近並點擊樓梯上下樓。此版本最多兩層。

家具可放在兩層：椅子以 1 口糧恢復 15 體力、餐桌開啟背包與工作功能、晶燈可開關。建築面板的「移動／拆除建築」可輸入整數格位搬移；展示池連同名稱與住民一起移動。地板、樓梯以拆除重建調整。建造面板底部列出所有建築，包含不能直接點選的地板。拆除需再點一次確認，回收各材料向下取整約 50%；有住民或預留幼體的展示池不能拆除，地基不可切斷木筏，二樓不可拆掉玩家腳下地板。

### 遺跡、洞窟與生存

御獸遠航的「航務與遺跡」頁可標記探索點。

1. 棕櫚環礁的漂流者寶箱提供一次性補給。
2. 沉城遺島的御獸石碑取得晶窟封印知識。
3. 登上異晶礁島，從晶窟入口進入獨立 3D 洞窟，調查封印寶箱；從出口返回原海岸。
4. 以羈絆 60 的夥伴深潛，在 (22, -34) 調查深海記憶核心。
5. 東方 (100, 40) 有體力 480 的巨型深海守望者。擊退一次獲異晶 12、金屬 15、口糧 5，並完成契印條件。

世界每 480 秒循環，約第 288～365 秒為風暴期。海上每 10 秒遭受船體衝擊傷害，岸上可避風；雨點與光線同步變化。小艇最高 3 級，每級增加航速 0.7 並降低風暴傷害 1.5，也減少海怪衝擊。升級需返回避難所 20 公尺內並支付木材、金屬及異晶。面板會列出當級費用。

## 0.7 單機體驗、Google Drive 雲端存檔、寫實畫面

為上架網站版、Google Play、Steam 做準備。各平台的打包方式、Google OAuth 設定步驟與原生橋接介面見 [`docs/PLATFORMS.md`](docs/PLATFORMS.md)。

### 免登入單機體驗

- 不用登入就能完整遊玩，進度自動存在此裝置（沿用舊存檔鍵值，舊進度保留）。
- 新增 `manifest.webmanifest` 與 service worker（`sw.js`），HTTPS 網站可安裝成 App，離線也能玩。之後也可以用 Trusted Web Activity 上架 Google Play。

### Google 登入與 Google Drive 存檔

- 標題畫面右上角的帳號卡、暫停選單都可以登入 Google。登入後存檔同步到該帳號 Google Drive 的 `appDataFolder`（應用程式專用的隱藏資料夾，遊戲讀不到其他檔案）。
- 每次存檔後最多 60 秒內上傳一次；切到背景、回主畫面或按「立即同步雲端」會立刻上傳。下次開啟時，按開始會自動重新連線並比對進度。
- 換裝置登入會自動下載較新的雲端進度。若裝置與雲端在上次同步後都有變更，會顯示兩份進度的天數、建築、御獸數與時間，讓玩家選擇保留哪一份。
- 登出後本機進度保留，可繼續單機遊玩。
- **需要設定**：在 `dist/config.js` 填入 Google OAuth 網頁用戶端 ID。留空時只有單機模式，也不會載入任何 Google 程式。

### 寫實畫面

- 物理風格天空：大氣漸層、日出日落暖色、體積感雲層、夜間星空與月亮。太陽跟著 HUD 時鐘移動（06:00 日出、12:00 正午、18:00 日落），陽光顏色、陰影方向與強度同步改變。
- 海面改用 Gerstner 波浪：真實的浪峰形狀、Fresnel 反射天空、GGX 太陽高光、浪峰透光、白浪，島嶼周圍的淺水色與岸邊浪花、船尾航跡。海面網格以鏡頭為中心，近處細密、遠處延伸到地平線。
- 以天空即時產生環境貼圖（PMREM），所有建築、生物與島嶼都會受天空光照與反射影響；霧色跟地平線顏色一致，遠景會自然淡入大氣中。
- 暫停選單可切換畫質：寫實／平衡／效能（觸控裝置預設「平衡」）。

### 驗證

`npm test` 全部通過，新增 6 項存檔協調、Drive 用戶端（模擬 API）、太陽時鐘與畫質設定測試。另以模擬的 Google 登入與 Drive API 在瀏覽器實測：訪客遊玩→登入上傳、新裝置登入下載、雙邊衝突選擇、登出。並截圖檢查正午、黃昏、夜間暴風與第一人稱地平線畫面。真實 Google 帳號登入要等填入用戶端 ID 後才能驗證；手機 GPU 效能仍需實機測試。

## 0.8 物理手感、音樂、手機多點觸控

### 更符合物理的海

- **浮力**：小艇、漂流物、野生生物都浮在畫面上看到的那片浪上。程式和海面著色器共用同一組 Gerstner 波浪（`dist/physics.js`），小艇會隨浪起伏、前後俯仰、左右搖晃。第一人稱坐船時視角也會跟著浪起伏。暴風會漸強漸弱，不再瞬間切換。
- **船的慣性**：小艇、戰艦、騎乘的御獸都有動量。推力只沿船頭方向，所以要先轉向才會加速。放開後會滑行減速；船底龍骨會抑制側滑；撞到東西會損失大部分速度。戰艦比小艇重，起步和轉彎都更慢。走路維持即時反應。
- **航跡**：改成記錄船實際走過的路線。每個點會向外擴散一圈波紋，所有波紋疊起來，就形成約 20° 的開爾文角 V 形尾浪（真實船隻的尾浪角度約 19.5°），中間是螺旋槳攪起的白色水流。轉彎時航跡會跟著彎曲，大約 9 秒後消失。船頭有船首浪，高速時會濺起水花。

### 驅離

- 船槳在船側拍水：合成的拍水聲（水聲衝擊、低沉悶響、落下的水滴聲），畫面有水花水滴和向外擴散的波紋。
- 生物不再瞬間移位：被嚇到時往遠離水花的方向急衝，再慢慢減速成正常游速。逃跑途中會稍微下潛再浮上來，擺尾也變快，最後停在游到的地方。

### 音樂（CC0 免費音樂庫）

- 5 首 CC0（公眾領域）曲目，可商用、不必標示作者。來源是 Free Music Archive，取自 [SoundSafari/CC0-1.0-Music](https://github.com/SoundSafari/CC0-1.0-Music) 的鏡像。作者與用途寫在 `dist/audio/music/CREDITS.md`：
  - 標題畫面：Komiku
  - 白天航行、夜晚／暴風、深海／洞窟／海怪：HoliznaCC0
  - 木筏、島上、戰艦甲板：Komiku
- 依情境自動切換，切換時交叉淡入淡出（同一情境維持 2.5 秒才換曲，避免來回跳動）。音樂以串流播放，不會整首解碼佔記憶體；iOS 也能調整音量。
- 新增依船速變化的水流聲。音效開關會記住，下次開啟遊戲沿用上次的設定。

### 邊移動邊收集

- 打撈時可以繼續航行：纜繩會把漂流物一路拖回船邊，拉超過 16 公尺才會鬆脫。
- 自動拾取（預設開啟）：駛過 3.6 公尺內的漂流物會自動拋繩，走過可採集的資源點會自動採集。

### 手機操作

- **多點觸控**：每根手指各自追蹤。左手推搖桿時，右手可以同時按打撈、驅離、登岸等按鈕。畫面上單指拖曳環視，雙指縮放或扭轉旋轉視角，搖桿操作不會被打斷。按鈕改在手指放開時觸發，避免部分手機瀏覽器同時兩指觸控時漏掉點擊。
- **加速**：搖桿旁新增「加速」鈕，點一下開啟，停下約 1 秒自動關閉，左手拇指就能操作。另外搖桿推到底約半秒也會自動加速。鍵盤用 Shift，手把左搖桿推到底。
- 按鈕按下有即時回饋，也取消了雙擊縮放造成的延遲。

### 驗證

- `npm test` 全部通過，新增 5 項物理測試：波浪連續性、浮力姿態、船的慣性與滑行、生物連續逃離、航跡記錄。
- 在瀏覽器實測並截圖：航跡形狀、驅離水花與生物逃離，以及音樂從標題→白天→夜晚→木筏的切換。
- 用模擬手機做多點觸控測試：搖桿推著不放的同時，另一指點驅離、開加速、雙指縮放，搖桿都持續作用。

## 0.9 操作舒適度

### 依操作裝置顯示提示

- 所有提示會依你正在用的裝置自動換字，包括內心獨白、任務、互動提示、跳出訊息、面板文字、新手教學和按鍵標籤：
  - 鍵盤：「按 E 打撈」
  - 觸控：「點互動鈕打撈」
  - 手把：「按 Ⓐ 打撈」
- 手把模式下，畫面上的按鍵標籤會換成手把按鈕（Ⓧ／LB／RB／LT／Select／L3…），右下角的操作說明也會換成手把版本。
- 設定可以固定成其中一種。
- 手把新增十字鍵 ← 騎乘、→ 潛水。

### 手機介面

- 手機橫放時，左上任務最多顯示兩項未完成；體力、水分、飽食不再壓到任務清單。
- 內心獨白在小螢幕上縮小，約 4 秒後收成一行。點一下展開，再點一下關閉。
- 跳出訊息移到畫面上方的提示框下面，不會互相遮擋。

### 回饋

- 撿到物資時，物資圖示會從撿起的位置飛進上方資源列（或背包鈕），該欄位會跳一下。
- 震動回饋：拾取、驅離、撞擊、受傷、新發現、暴風預警時會震動。Android 手機會震動，支援的手把會震動；iPhone 瀏覽器不支援震動。

### 設定頁

暫停選單與標題畫面都有「⚙ 設定」。設定只存在這台裝置，可調整：

- 畫質
- 字體大小：標準／大／特大
- 音量：音樂、音效、環境聲各自調整
- 鏡頭靈敏度、上下反轉
- 自動拾取
- 震動回饋
- 按鍵提示：自動／鍵盤／觸控／手把
- 手機按鈕大小：小／標準／大
- 左右手對調：搖桿在右，動作鈕在左
- 重新播放新手教學

### 暴風預警

- 暴風前 30 秒，畫面上方出現倒數提示，搭配提示音與震動。
- 還在海上時，提示框會顯示「前往（最近的避風處）· 距離」按鈕，點一下自動導航過去；避風處可以是避難所，也可以是最近的島嶼岸邊。小地圖會用閃爍的「避」字標出位置。
- 暴風期間提示框持續顯示剩餘時間。已經上岸、在船內、在洞窟或潛水時，會顯示「已在避風處」。

### 新手教學

- 新開局時，會用 4 個步驟帶著實際操作：駕艇 → 打撈 → 登上木筏 → 擴建地基。
- 每一步都會讓對應的按鈕發光。已經做到的步驟會自動跳過，例如開船時已經自動撿到物資。隨時可以按「跳過教學」。
- 教學期間，內心獨白先不跳出來；完成後再接著出現。
- 舊存檔不會出現教學，但可以在設定裡重新播放。

### 修正

- 打撈纜繩還沒收回時按 Q 登岸，原本會沒有任何反應。現在會先把物資拉上船（或放掉太遠的纜繩），再登岸。這個問題在加入自動拾取後很容易遇到。
